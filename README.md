# Contenido del curso de Programación Avanzada

1. Instalaciones necesarias

Para el correcto desarrollo del curso, el estudiante deberá contar con las siguientes herramientas previamente instaladas y configuradas en su equipo de trabajo

1.1 Python

Lenguaje de programación principal del curso. Se recomienda instalar la versión estable más reciente (Python 3.x).

Sitio oficial de descarga:https://www.python.org/

Durante la instalación, es importante activar la opción Add Python to PATH.

1.2 Git

Sistema de control de versiones distribuido, utilizado para la gestión del código fuente y el trabajo colaborativo.

Sitio oficial de descarga:https://git-scm.com/

Se recomienda verificar la instalación ejecutando en la terminal:

git --version

1.3 Visual Studio Code (VS Code)

Editor de código fuente que se utilizará como entorno de desarrollo principal durante el curso.

Sitio oficial de descarga:https://code.visualstudio.com/

1.4 Cuenta en GitHub

Plataforma de alojamiento de repositorios Git que se utilizará para prácticas, proyectos y entregas del curso.

Registro de cuenta:https://github.com/

El estudiante deberá contar con una cuenta activa antes de iniciar las actividades prácticas.

1.5 Arduino software
Entorno de desarrollo para la programación y carga de firmware en placas Arduino, utilizado en prácticas de integración con Python y sistemas embebidos.

Sitio oficial de descarga:https://www.arduino.cc/en/software/

2. Extensiones recomendadas para Visual Studio Code

Para optimizar el entorno de desarrollo, se deberán instalar las siguientes extensiones desde el marketplace de Visual Studio Code.

2.1 Spanish Language Pack for Visual Studio Code

Permite utilizar la interfaz del editor en idioma español, facilitando su uso.

2.2 Python

Extensión oficial para el desarrollo en Python. Proporciona:

Soporte de sintaxis

Autocompletado

Análisis estático del código

Ejecución de scripts

Integración con entornos virtuales

2.3 Python Debugger

Herramienta para depuración de programas en Python, que permite:

Colocar puntos de interrupción

Inspeccionar variables

Analizar el flujo de ejecución

Detectar errores lógicos y de ejecución

2.4 Pylance

Motor avanzado de análisis estático para Python. Mejora significativamente la experiencia de desarrollo mediante:

Autocompletado inteligente basado en tipos

Detección temprana de errores

Navegación eficiente entre definiciones

Soporte avanzado de tipado (type hints)

2.5 Jupyter

Extensión para el uso de notebooks Jupyter dentro de Visual Studio Code. Resulta especialmente útil para:

Análisis de datos

Visualización de resultados

Prototipado rápido de algoritmos

Documentación interactiva del código
